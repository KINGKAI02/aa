RIYA BIRTHDAY WEBSITE
=======================

Files:
- index.html : complete website

How to use:
1. Open index.html in any browser to preview it.
2. To get a shareable public link, upload index.html to a static hosting service such as GitHub Pages, Netlify, or Vercel.
3. The page is mobile-friendly and works without a backend.

Note:
The page uses Google Fonts, so the font may fall back to a system font if the visitor is offline.
